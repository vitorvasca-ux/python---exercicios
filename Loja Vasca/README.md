# Loja Vasca

Projeto de gerenciamento de produtos da Loja Vasca, com persistência em SQLite.

## Requisitos

- Python 3

O SQLite já faz parte da biblioteca padrão do Python; não é necessário instalar pacotes adicionais.

## Como executar

No terminal, dentro desta pasta, execute:

```bash
python Produtos.py
```

Na primeira execução, o programa cria o arquivo `Loja_Vasca.db` e as tabelas necessárias. O menu permite cadastrar, listar e buscar produtos.
